Date: 2026-06-01

Source issue: https://github.com/raichiiiiiii/Blockchain-Based-E-Procurement-System/issues/25

## Scope

This matrix validates whether each actor has an executable business purpose, not only a role-specific dashboard. It compares the current repository against the academic procurement/use-case baseline from the attached procurement blockchain paper, procurement productivity thesis, and mudarabah procurement thesis.

Verdict values:

- Executable: actor can complete at least one useful governed action through backend-backed product or API behavior.
- Partial: actor can inspect useful state but at least one expected core action is simulated, local-only, or missing.
- Gap: actor exists but does not yet have a useful executable workflow.
