# Actor Workflow Acceptance Matrix

Date: 2026-05-26
Status: Commercial-readiness planning baseline
Scope: Digital Procurement and PLS Seedbed MVP

## Purpose

This matrix maps each mandatory actor to entry point, route, core action, backend dependency, audit/proof expectation, UAT evidence, current readiness, gaps, and release relevance. It does not alter backlog statuses.

Matrix status values:

```text
Ready
Partially Ready
Planned
Deferred
Blocked
```

## Release Notes

- Backend authorization tests remain the authoritative access-control evidence; hidden UI navigation is not treated as security by itself.
- Raw KYC/AML data, raw escrow terms, payment credentials, and private commercial documents must not appear in dashboard cards.
- The matrix marks MVP actor flows as ready when they satisfy the current release baseline, even when post-MVP production hardening remains.
- Security Operator is should-have, not mandatory, and remains read-only MVP scope.
